Conoce DiscVault 26

DiscVault 26 es un gestor de colección autoalojado para 4K UHD, Blu-ray y DVD. Esta documentación te ayuda a instalarlo, usarlo a diario, administrarlo con seguridad y conectar asistentes de IA mediante MCP.

Bajo el capó

Un contenedor, varias partes

Frontend/PWAResponsive webapp met cached app-shell en beperkte offline leesfallback; wijzigingen schrijven vereist backend-connectiviteit.
APIRoutes voor films, imports, watchlist, auth, groups, settings, backups en push.
Data & assetsPersistente data in /data: collectiedata, posters, avatars, profielen en backups.
MCPStreamable HTTP endpoint via /mcp, bij voorkeur met persoonlijke API-key per gebruiker.

No prometer de más

Notas importantes de alcance

Autoalojado, no SaaS

DiscVault se ejecuta en tu propio entorno Docker o Unraid. Estas docs no prometen alojamiento cloud ni servicio gestionado.

La PWA no funciona totalmente sin conexión

La carcasa de la app y el modo de lectura pueden cachearse; las acciones que cambian datos siguen necesitando conexión con el backend.

MCP respeta el alcance del usuario

Usa claves API personales para que las herramientas de IA solo vean los datos que pertenecen a ese usuario.
