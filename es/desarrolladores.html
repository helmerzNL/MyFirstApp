Notas importantes de alcance

Autoalojado, no SaaSDiscVault se ejecuta en tu propio entorno Docker o Unraid. Estas docs no prometen alojamiento cloud ni servicio gestionado.
La PWA no funciona totalmente sin conexiónLa carcasa de la app y el modo de lectura pueden cachearse; las acciones que cambian datos siguen necesitando conexión con el backend.
MCP respeta el alcance del usuarioUsa claves API personales para que las herramientas de IA solo vean los datos que pertenecen a ese usuario.
