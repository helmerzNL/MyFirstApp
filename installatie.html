Installatie

Docker en Unraid quickstart

Start DiscVault Next als all-in-one container. De web UI/API draait standaard op hostpoort 6080; MCP kan via /mcp of optioneel via poort 6090.

Docker-runUnraid-template

Quickstart

Start met Docker

docker run -d \
  --name discvault \
  -p 6080:80 \
  -p 6090:6090 \
  -e TZ=Europe/Amsterdam \
  -e RP_ID=localhost \
  -e RP_ORIGIN=http://localhost:6080 \
  -v /mnt/user/appdata/discvault:/data \
  ghcr.io/helmerzNL/DiscVault:latest

Open daarna de webapp

Ga naar http://localhost:6080. Gebruik in productie een echte hostnaam en HTTPS, zodat passkeys betrouwbaar werken.

Configuratie

Instellingen die je moet begrijpen

/data
Persistent volume met SQLite database, posters, profielen, avatars en backups. Zet dit op appdata/storage die updates overleeft.
RP_ID
Domein of hostnaam waarvoor passkeys geldig zijn, bijvoorbeeld discvault.example.nl.
RP_ORIGIN
Volledige origin inclusief protocol, bijvoorbeeld https://discvault.example.nl.
OMDB_API_KEY / TMDB_API_KEY
Optionele metadata keys voor rijkere filmdata en artwork.
JWT_SECRET
Eigen secret voor sessies/tokens. Gebruik een unieke waarde in productie.
