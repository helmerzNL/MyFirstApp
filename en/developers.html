Important scope notes

Self-hosted, not SaaSDiscVault runs in your own Docker or Unraid environment. These docs do not claim cloud hosting or a managed service.
The PWA is not fully offlineThe app shell and read fallback can be cached; actions that change data still need backend connectivity.
MCP is user-scopedUse personal API keys so AI tools only see data that belongs to that user.
