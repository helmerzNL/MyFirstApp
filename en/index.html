Get to know DiscVault 26

DiscVault 26 is a self-hosted collection manager for 4K UHD, Blu-ray and DVD. These docs help you install it, use it day to day, manage it safely and connect AI assistants through MCP.

Do not overclaim

Important scope notes

Self-hosted, not SaaS

DiscVault runs in your own Docker or Unraid environment. These docs do not claim cloud hosting or a managed service.

The PWA is not fully offline

The app shell and read fallback can be cached; actions that change data still need backend connectivity.

MCP is user-scoped

Use personal API keys so AI tools only see data that belongs to that user.
