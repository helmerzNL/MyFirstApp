PanoramicaFAQ

Self-hosted, non SaaS

DiscVault gira nel tuo ambiente Docker o Unraid. Queste docs non promettono hosting cloud né un servizio gestito.

La PWA non è completamente offline

L’app shell e il fallback in lettura possono essere memorizzati in cache; le azioni che modificano dati richiedono comunque il backend.

MCP è legato all’utente

Usa chiavi API personali, così gli strumenti IA vedono solo i dati appartenenti a quell’utente.
