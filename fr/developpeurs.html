Notes de périmètre importantes

Auto-hébergé, pas un SaaSDiscVault tourne dans votre propre environnement Docker ou Unraid. Ces docs ne promettent ni hébergement cloud ni service managé.
La PWA n’est pas totalement hors ligneL’enveloppe de l’app et le mode lecture peuvent être mis en cache ; les actions qui modifient des données nécessitent toujours le backend.
MCP est limité à l’utilisateurUtilisez des clés API personnelles afin que les outils IA ne voient que les données de l’utilisateur concerné.
