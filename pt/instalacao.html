Notas importantes de âmbito

Self-hosted, não SaaSO DiscVault corre no seu próprio ambiente Docker ou Unraid. Esta documentação não promete alojamento cloud nem serviço gerido.
A PWA não é totalmente offlineA app shell e o modo de leitura podem ser colocados em cache; ações que alteram dados continuam a precisar do backend.
MCP respeita o utilizadorUse chaves API pessoais para que ferramentas de IA vejam apenas os dados pertencentes a esse utilizador.
