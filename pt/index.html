Conheça o DiscVault 26

O DiscVault 26 é um gestor de coleção self-hosted para 4K UHD, Blu-ray e DVD. Esta documentação ajuda a instalar, usar no dia a dia, administrar com segurança e ligar assistentes de IA através de MCP.

Nos bastidores

Um contentor, várias partes

Frontend/PWAResponsive webapp met cached app-shell en beperkte offline leesfallback; wijzigingen schrijven vereist backend-connectiviteit.
APIRoutes voor films, imports, watchlist, auth, groups, settings, backups en push.
Data & assetsPersistente data in /data: collectiedata, posters, avatars, profielen en backups.
MCPStreamable HTTP endpoint via /mcp, bij voorkeur met persoonlijke API-key per gebruiker.

Notas importantes de âmbito

Self-hosted, não SaaS

O DiscVault corre no seu próprio ambiente Docker ou Unraid. Esta documentação não promete alojamento cloud nem serviço gerido.

A PWA não é totalmente offline

A app shell e o modo de leitura podem ser colocados em cache; ações que alteram dados continuam a precisar do backend.

MCP respeita o utilizador

Use chaves API pessoais para que ferramentas de IA vejam apenas os dados pertencentes a esse utilizador.
