Hoe DiscVault Next werkt

DiscVault Next is een moderne, self-hosted app om je 4K UHD, Blu-ray en DVD-collectie te beheren. Deze documentatie legt de onderdelen uit: van barcode-scan tot metadata, gebruikers, groepen, backups, PWA en MCP voor AI-workflows.

Start met de quickstart Bekijk broncode

In één zin

DiscVault Next is je privé-catalogus voor fysieke films, met een webapp, backend API, SQLite database en optionele MCP-server voor AI-assistenten.

  • Barcode scannen of handmatig toevoegen
  • Metadata via OMDb en TMDb fallback
  • Meerdere gebruikers en groepen
  • Watchlist, kijkgeschiedenis en notificaties
  • MCP endpoint voor persoonlijke AI-toegang

Productoverzicht

Wat is DiscVault Next?

Collectie beheren

Voeg fysieke films toe via barcode-scan of handmatige invoer. DiscVault haalt automatisch metadata en artwork op waar mogelijk.

Zelf hosten

Je draait DiscVault in je eigen omgeving, bijvoorbeeld Docker of Unraid. De database en uploads blijven in je eigen data-map.

AI-ready

Met de MCP-server kan een AI-assistent je eigen collectie doorzoeken, details ophalen en acties uitvoeren binnen jouw rechten.

Onder de motorkap

Architectuur

DiscVault Next bestaat uit meerdere onderdelen die samen als één applicatie kunnen draaien.

FrontendStatische webapp/PWA, geserveerd via Nginx.
Backend APIFlask + Gunicorn voor auth, films, imports, backups, logs en instellingen.
DatabaseSQLite database in de persistente /data map.
MCP-serverStreamable HTTP endpoint waarmee AI-clients veilig met DiscVault praten.
ContainerAll-in-one Docker image met Nginx, backend en supervisord.

Snel starten

Quickstart met Docker

docker run -d \
  --name discvault \
  -p 6080:80 \
  -p 6090:6090 \
  -e TZ=Europe/Amsterdam \
  -e RP_ID=localhost \
  -e RP_ORIGIN=http://localhost:6080 \
  -v /mnt/user/appdata/discvault:/data \
  ghcr.io/helmerzNL/DiscVault:latest

Open daarna http://localhost:6080. Voor Unraid gebruik je de Community Applications template uit de DiscVault template-repo.

Configuratie

Belangrijke instellingen

Verplicht voor realistische login

RP_ID
Domein of hostnaam waarop passkeys geldig zijn.
RP_ORIGIN
Volledige origin, bijvoorbeeld https://discvault.example.nl.
TZ
Tijdzone, bijvoorbeeld Europe/Amsterdam.

Optioneel

OMDB_API_KEY
Metadata ophalen via OMDb.
TMDB_API_KEY
Fallback metadata via TMDb.
JWT_SECRET
Eigen secret voor sessies/tokens.
MCP_API_KEY
Alleen voor oudere/global MCP-config; per-user API keys hebben de voorkeur.

AI-integratie

MCP: DiscVault koppelen aan een AI-assistent

Iedere gebruiker kan in DiscVault een persoonlijke API-sleutel maken. Die sleutel bepaalt welke collectie, watchlist, kijkgeschiedenis en groepen de AI mag zien.

{
  "mcpServers": {
    "discvault": {
      "transport": "streamable-http",
      "url": "http://your-server:6080/mcp",
      "headers": {
        "Authorization": "Bearer your-personal-api-key"
      }
    }
  }
}

Zoeken

search_collection, list_all_movies en get_movie_details.

Beheren

add_movie, delete_movie en lookup_barcode.

Persoonlijk

get_watchlist, get_watch_history en get_groups.
