Onder de motorkap

Eén container, meerdere onderdelen

Frontend/PWAStatische webapp met responsive collectie, cached app-shell en offline read fallback.
Flask APIRoutes voor films, imports, watchlist, auth, groups, settings, backups en push.
SQLite + assetsPersistente data in /data: database, posters, avatars, profielen en backups.
MCPStreamable HTTP endpoint via /mcp, bij voorkeur met persoonlijke API-key per gebruiker.

Niet overclaimen

Belangrijke scope-notities

Self-hosted, geen SaaS

DiscVault draait in je eigen Docker/Unraid-omgeving. Deze docs claimen geen cloudhosting of managed service.

PWA is niet volledig offline

De app-shell en leesfallback kunnen cachen; schrijfacties hebben backend-connectiviteit nodig.

MCP is user-scoped

Gebruik persoonlijke API-sleutels zodat AI-tools alleen data zien die bij die gebruiker hoort.
