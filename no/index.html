Self-hosted dokumentasjon for fysiske medier

Bli kjent med DiscVault 26

DiscVault 26 er en self-hosted samlingsbehandler for 4K UHD, Blu-ray og DVD. Dokumentasjonen hjelper deg å installere, bruke løsningen i hverdagen, administrere trygt og koble til AI-assistenter via MCP.

De viktigste arbeidsflytene

Dokumentasjonen er delt i små statiske sider, slik at GitHub Pages kan hoste dem direkte uten build-pipeline.

Installere

Kjør all-in-one-containeren med web UI, API og MCP-tjeneste. Hold /data persistent for samlingsdata, plakater, profiler og sikkerhetskopier.

Under panseret

Én container, flere deler

Frontend/PWAResponsive webapp met cached app-shell en beperkte offline leesfallback; wijzigingen schrijven vereist backend-connectiviteit.
APIRoutes voor films, imports, watchlist, auth, groups, settings, backups en push.
Data & assetsPersistente data in /data: collectiedata, posters, avatars, profielen en backups.
MCPStreamable HTTP endpoint via /mcp, bij voorkeur met persoonlijke API-key per gebruiker.

Ikke lov for mye

Viktige merknader om omfang

Self-hosted, ikke SaaS

DiscVault kjører i ditt eget Docker- eller Unraid-miljø. Disse docs lover ikke skyhosting eller en administrert tjeneste.

PWA-en er ikke helt offline

App-skallet og lesefallback kan caches; handlinger som endrer data krever fortsatt backend-tilkobling.

MCP følger brukerens tilgang

Bruk personlige API-nøkler, slik at AI-verktøy bare ser data som tilhører den brukeren.
